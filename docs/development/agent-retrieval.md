# Semantic retrieval

`ath_semantic_search` searches explicitly selected file resources, knowledge revisions and owned message IDs. It does not scan every project or conversation automatically. Source identity, revision/hash, location and exact returned text accompany every citation. Results are semantic candidates, not factual approval or test acceptance.

The application service rechecks current owner/project/source authority before indexing and before returning results. Its PostgreSQL cache is keyed by owner, selection, immutable source stamp and semantic model revision. File deletion, knowledge revision changes and message edits invalidate the corresponding cache. Cached vectors never grant access to cached text. Privacy recovery must call `redactAgentRetrievalSource` for conversation/resource erasure in restored backups.

PDF and Office inputs use the same bounded document parser as normal chat references. Scanned pages and embedded images have no fabricated OCR index: the response reports missing visual coverage and retains page/structure positions for real multimodal reading. Partial structure ranges, chunk limits and tokenizer truncation are explicit. Continue with a narrower range or use `ath_document_read` for the original page images.

## Local encoder and reranker

The independent encoder uses fixed quantized multilingual E5 weights from [Xenova/multilingual-e5-small](https://huggingface.co/Xenova/multilingual-e5-small/tree/761b726dd34fb83930e26aab4e9ac3899aa1fa78), derived from the MIT-licensed [intfloat model](https://huggingface.co/intfloat/multilingual-e5-small). Model and tokenizer bytes are SHA-256 checked during build and startup. The CPU runtime uses the documented query/passage prefixes, attention-mask average pooling and normalized 384-dimensional vectors.

Retrieval has two stages. Cosine similarity with a small lexical contribution selects at most 32 chunks. The fixed MIT-licensed [BGE reranker](https://huggingface.co/Xenova/bge-reranker-base/tree/280bcc27a84e0b898c251e06fddb25171bd9b101), derived from [BAAI/bge-reranker-base](https://huggingface.co/BAAI/bge-reranker-base), then scores each query/chunk pair. Its relative relevance logits determine the returned order; they are not calibrated probabilities or factual judgments. The response retains vector and lexical scores and reports the exact reranker revision, candidate count and pair truncation. Reranking errors fail the search; the production client does not silently return the earlier ordering. Initial vector recall is bounded, so reranking cannot recover chunks outside those 32 candidates.

Build `deploy/local/Dockerfile.embedding` with its exact hashed Python requirements and provision its fixed public assets. The runtime never downloads models. Preserve installed wheel licenses, both upstream model licenses and the generated model notice. `deploy/local/compose.embedding.yaml` is a private-network template; provision an immutable image and an independent restricted token file, then attach only the authorized API/AI worker. Its normal limit is one CPU and 2 GiB of memory, with a read-only root, dropped capabilities and bounded temporary storage. This trusted model service is separate from the untrusted code sandbox and does not increase its limits. No public or host port, internet route, writable host workspace or Docker socket is needed.

Composition roots use `createSemanticEmbeddingFromEnvironment` with `AITESTHUB_EMBEDDING_ORIGIN` and `AITESTHUB_EMBEDDING_TOKEN_FILE`. Secrets remain in files and are never model arguments. A missing service is reported as unavailable, not as successful semantic retrieval. The fixed HTTP service accepts only bounded text arrays at `/embed` and query/text pairs at `/rerank`; it has no code, URL, path or model-selection operation. Each request contains at most 16 texts. The client splits the 32 reranking candidates into two requests; CPU inference uses batches of four embeddings or two pairs. Both models have a 512-token window, and actual tokenizer truncation is returned explicitly. It does not log request bodies or credentials.

Cancellation aborts the client request and prevents subsequent batches or returned search results. A pair already executing in the independent service may finish its bounded HTTP batch before the single service worker accepts another request; cancellation does not claim to preempt ONNX inference. Source authority and source stamps are rechecked before sending indexed text to a model and again before returning citations.
